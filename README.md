# DimLife IRC

**DimLife IRC** — Android IRC-клиент проекта DimLife. Это самостоятельная сборка на основе открытого проекта [HexDroid](https://github.com/boxlabss/HexDroid), с сохранением исходных возможностей и дальнейшей адаптацией под экосистему DimLife.

## Возможности

- Несколько IRC-сетей и профилей подключения
- TLS, SASL и поддержка IRCv3
- Поддержка ZNC и soju bouncer
- Личные сообщения и каналы, уведомления и фоновое подключение
- DCC-передача файлов и DCC-чат
- Поддержка скриптов и команд
- Функции шифрования переписки, доступные в исходном проекте
- Темы оформления и многоязычный интерфейс

Некоторые возможности зависят от конфигурации IRC-сервера и используемых расширений.

## Сборка APK

1. Откройте вкладку **Actions** этого репозитория.
2. Выберите **Build DimLife IRC APK**.
3. Нажмите **Run workflow** и запустите сборку.
4. После завершения откройте запуск workflow и скачайте артефакт **dimlife-irc-apks-[run number]**.

В артефакте будет debug APK для установки и проверки. Release APK собирается отдельно; если в репозитории настроены секреты подписи, он будет подписан. Для публикации release через тег `v*` требуется настроенная подпись.

## Технологии

- Kotlin
- Jetpack Compose
- Material Design 3
- Android SDK

Минимальная версия Android: 8.0 (API 26).
